# Keitaro Wrapper

Веб-сервис поверх Admin API трекера [Keitaro](https://keitaro.io):

1. **Создание кампании.** Вы вводите название, гео и оффер. Сервис создаёт кампанию с доменом, группой и источником и двумя потоками: первый отправляет посетителей из указанных стран на Google, второй — всех остальных на оффер.
2. **Редактор кампании.** Позволяет добавлять, удалять и возвращать офферы, закреплять доли и смотреть статистику.

**Стек:** FastAPI, SQLAlchemy 2.0 (async), Alembic, SQLite, фронтенд на HTML/JS.

## Запуск

Нужен Python 3.11 или новее.

```bash
git clone https://github.com/qravemzxc/KeitaroWrapper.git keitaro-wrapper
cd keitaro-wrapper

python -m venv .venv
# Windows (PowerShell):  .venv\Scripts\Activate.ps1
# Linux / macOS:         source .venv/bin/activate
pip install -r requirements.txt
```

Создайте в корне проекта файл `.env`:

```ini
KEITARO_API_KEY=ваш-ключ          # Keitaro → Профиль → API ключи
CAMPAIGN_PREFIX=test_фамилия_     # префикс названий кампаний
```

Примените миграции и запустите сервер:

```bash
alembic upgrade head
uvicorn app.main:app --port 8000
```

После запуска откройте:

- **интерфейс** — http://localhost:8000;
- **Swagger** — http://localhost:8000/docs.

## Миграции

Миграции лежат в `alembic/versions`. База по умолчанию — SQLite (`./keitaro_wrapper.db`), строка подключения берётся из `DATABASE_URL`.

```bash
alembic upgrade head                            # применить все миграции
alembic downgrade -1                            # откатить последнюю
alembic current                                 # текущая версия схемы
alembic revision --autogenerate -m "описание"   # новая миграция после изменения app/models.py
```

## Как пользоваться

**Новая кампания.** Введите:

- **название** — префикс добавится сам;
- **гео** — коды стран через запятую, например `MX, AU, RO`;
- **оффер** — ID или часть названия, затем выберите его из подсказок.

После этого нажмите «Создать».

**Редактор кампаний.** Выберите кампанию в списке слева. В потоке с офферами доступны действия:

- **Добавить** — новый оффер попадает в черновик;
- **урна** — оффер помечается на удаление и становится тусклым с долей 0%, рядом появляется кнопка «↩ Вернуть»;
- **булавка** — закрепляет долю оффера: при добавлении и удалении других офферов она не меняется, а остаток делится поровну. Повторное нажатие снимает закрепление и пересчитывает доли;
- **⇪ Запушить в Keitaro** — отправляет изменения черновика в Keitaro. Доли пересчитываются поровну с учётом закреплённых;
- **⟳ Обновить офферы** — перечитывает данные из Keitaro. Оффер, удалённый на сайте Keitaro, остаётся в списке со статусом «удалён», и его можно вернуть.

Колонки «Клики», «Уник.», «Боты» и «Трендс» показываются за выбранный период. «Трендс» сравнивает клики с предыдущим таким же периодом.

## Настройки `.env`

Обязательны только `KEITARO_API_KEY` и `CAMPAIGN_PREFIX`. Остальные значения по умолчанию подходят для тестового аккаунта.

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `KEITARO_URL` | `https://tlgk.host` | Адрес трекера |
| `DEFAULT_DOMAIN_ID` / `DEFAULT_GROUP_ID` / `DEFAULT_TRAFFIC_SOURCE_ID` | `1813` / `10332` / `836` | Домен, группа и источник новой кампании |
| `GOOGLE_URL` | `https://google.com` | Куда первый поток отправляет посетителей из выбранных стран |
| `STATS_TIMEZONE` | пусто (пояс трекера) | Часовой пояс статистики |
| `TRACKER_TIMEZONE` | `UTC` | Пояс трекера для колонки «Трендс» |
| `DATABASE_URL` | `sqlite+aiosqlite:///./keitaro_wrapper.db` | Подключение к БД |

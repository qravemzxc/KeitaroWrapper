# Keitaro Wrapper

Обёртка над [Keitaro](https://keitaro.io) Admin API. Сделана на FastAPI, SQLAlchemy 2.0 (async) и Alembic, фронт написан на чистом HTML/JS без сборки.

1. **Создание кампаний.** На входе название, гео (один или несколько ISO-кодов стран) и ID оффера. Сервис создаёт кампанию в Keitaro с доменом, группой и источником и двумя потоками:
   - **поток 1**: фильтр «Страны принимать: …», редирект на `https://google.com`;
   - **поток 2**: все остальные посетители уходят на выбранный оффер (доля 100%).
2. **Редактор существующей кампании.** Добавляет и удаляет офферы в потоке с офферами и пересчитывает их доли. Показывает потоки, фильтры и статистику (клики, уникальные, боты, конверсии, доход) за выбранный период.

## Быстрый старт

Нужен Python 3.11+.

```bash
git clone <repo-url> keitaro-wrapper && cd keitaro-wrapper

python -m venv .venv
# Windows:   .venv\Scripts\activate
# Linux/Mac: source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env        # Windows: copy .env.example .env
# в .env впишите KEITARO_API_KEY и CAMPAIGN_PREFIX=test_<фамилия>_

alembic upgrade head        # создаёт БД и таблицы (SQLite: ./keitaro_wrapper.db)
uvicorn app.main:app --reload --port 8000
```

После запуска:
- UI: http://localhost:8000. Вкладка «Новая кампания» для создания, «Редактор кампаний» для правок.
- Swagger: http://localhost:8000/docs

API-ключ лежит в админке Keitaro: «Профиль» → «API ключи».

## Миграции

Миграции хранятся в `alembic/versions`. Строка подключения берётся из `DATABASE_URL` в `.env`, файл `alembic/env.py` читает её через настройки приложения.

```bash
alembic upgrade head                              # применить все миграции
alembic downgrade -1                              # откатить последнюю
alembic revision --autogenerate -m "описание"     # создать миграцию после изменения app/models.py
alembic current                                   # текущая ревизия
```

По умолчанию используется SQLite. Для Postgres выполните `pip install asyncpg` и укажите
`DATABASE_URL=postgresql+asyncpg://user:pass@host/db`.

## Тесты

```bash
pytest
```

Тесты не обращаются к реальному Keitaro: его API подменён in-memory фейком через `httpx.MockTransport` (см. `tests/conftest.py`). Проверяется следующее:
- структура созданной кампании и потоков;
- откат кампании, если поток не создался;
- пересчёт долей при добавлении и удалении офферов;
- ручные доли и валидация суммы;
- синхронизация локальной БД и журнал операций.

## Как это работает

### Создание кампании (`POST /api/campaigns`)

```json
{"name": "campaign1", "geo": "MX, AU, RO", "offer_id": 25327}
```

1. Проверяется, что оффер существует. Если его нет, в Keitaro ничего не создаётся.
2. К имени добавляется префикс `CAMPAIGN_PREFIX`, например `test_ivanov_campaign1`.
3. `POST /campaigns`: `type=position`, то есть потоки проверяются сверху вниз. Задаются домен, группа, источник и случайный alias.
4. `POST /streams` для потока 1: `schema=redirect`, `action_type=http` → Google, фильтр `country / accept / [MX, AU, RO]`.
5. `POST /streams` для потока 2: `schema=landings`, `offers=[{offer_id, share: 100}]`.
6. Если какой-то поток не создался, кампания удаляется, чтобы не оставлять её полунастроенной.
7. Кампания сохраняется в локальную БД, операция записывается в журнал.

Домен, группу и источник по умолчанию задают переменные `DEFAULT_*` в `.env`. В UI их можно поменять в блоке «Домен, группа, источник». Для тестового аккаунта это `kylovoa.com`, `FORTESTS` и `FORTESTS`.

### Редактор

| Метод | URL | Что делает |
|---|---|---|
| GET | `/api/campaigns?mine=true&q=` | список кампаний (`mine` оставляет только кампании с вашим префиксом) |
| GET | `/api/campaigns/{id}?interval=today` | кампания, потоки, офферы с долями и статистикой |
| POST | `/api/campaigns/{id}/offers` `{"offer_id": 1}` | добавить оффер, доли пересчитываются поровну |
| DELETE | `/api/campaigns/{id}/offers/{offer_id}` | удалить оффер, доли пересчитываются поровну |
| PUT | `/api/campaigns/{id}/shares` | задать доли вручную (сумма должна быть 100) |
| GET | `/api/campaigns/{id}/history` | журнал изменений, сделанных через сервис |
| GET | `/api/offers?q=` | автокомплит офферов по ID или названию |
| GET | `/api/meta` | домены, группы, источники и значения по умолчанию |

**Доли.** Keitaro требует, чтобы сумма долей офферов в потоке была равна 100. При добавлении или удалении оффера доли делятся поровну, а остаток от деления отдаётся первым офферам, как это делает сам Keitaro: 1 оффер → 100, 2 → 50/50, 3 → 34/33/33, 6 → 17/17/17/17/16/16. Доли можно выставить и вручную; кнопка «Сохранить» активна только при сумме ровно 100%.

Защиты в редакторе:
- нельзя добавить оффер, который уже есть в потоке, или несуществующий оффер;
- нельзя удалить последний оффер, иначе поток останется пустым.

**Какой поток редактируется.** По умолчанию первый поток со `schema=landings` или с офферами. Если в кампании несколько потоков с офферами, у каждого в UI своя форма, а в API нужный поток передаётся параметром `stream_id`.

`PUT /streams/{id}` в Keitaro заменяет весь список `offers`. Поэтому сервис каждый раз отправляет полный список с новыми долями, а существующие офферы Keitaro сопоставляет по `offer_id`.

**Статистика** берётся из `POST /report/build` с измерениями `stream_id` и `offer_id` и фильтром по кампании. Это те же цифры, что в колонках «Клики / Уник. / Боты» в интерфейсе Keitaro.

### База данных

Источник истины — Keitaro. Локальная БД хранит зеркало и журнал:

- `campaigns`: кампании (keitaro_id, имя, alias, url, гео, домен, группа, источник, id потоков);
- `campaign_offers`: текущие офферы потока с долями, синхронизируются после каждого изменения и при открытии кампании;
- `operation_log`: журнал операций (создание, добавление и удаление оффера, ручные доли) с итоговыми долями.

## Структура

```
app/
  main.py       FastAPI-приложение и роуты
  services.py   бизнес-логика: создание, редактор, синхронизация, статистика
  keitaro.py    async-клиент Keitaro Admin API
  shares.py     расчёт долей
  models.py     модели SQLAlchemy
  schemas.py    Pydantic-схемы и валидация (гео-коды и т.п.)
  config.py     настройки из .env
  static/       фронт (index.html, app.js, app.css)
alembic/        миграции
tests/          тесты (фейковый Keitaro)
```
